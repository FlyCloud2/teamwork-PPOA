# Windows 上安装顺序有讲究：
#   1) 先装 python 3.10（3.12+ 没有 distutils 兼容层，CleanRL 的 strtobool 导入会失败；

#        pip install torch==2.4.1 --index-url https://download.pytorch.org/whl/cu121
#   3) 其余都从本文件装
